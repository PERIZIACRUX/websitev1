/**
 * components/shared/README.md
 * ──────────────────────────────────────────────────────────────────────────
 * Shared Components
 *
 * Components in this directory are used across both CRUX and PERIZIA.
 * Examples:
 *   - Navigation bar
 *   - Footer
 *   - Button
 *   - Input fields
 *   - Modal / Dialog
 *   - Toast notifications
 *   - Loading skeletons
 *   - Error boundary
 *
 * Rules:
 *   - Shared components are purely presentational (dumb components).
 *   - They accept typed props and render UI only.
 *   - They do NOT call database functions, services, or external APIs.
 *   - Business logic is always in the server layer.
 */
